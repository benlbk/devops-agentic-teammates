# Design: Add Error Rate Display

## User Story
As a DevOps engineer, I want to see error 

## Architecture

### Components
- **ErrorRateColumn** (component): Table column component to display error rate percentage with threshold indicators
- **ErrorRateFormatter** (service): Utility service to format error rate values and handle calculations


### API Contracts
- `GET /api/services/{serviceId}/metrics` — Fetch service metrics including error rate


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client

## Technology Stack
- Frontend: Next.js 14+ with TypeScript, React, Tailwind CSS
- Backend: ASP.NET Core 8+ with C#, Entity Framework Core
- Database: PostgreSQL
- Infrastructure: AWS EKS, Terraform

## Security Considerations
- Input validation on all endpoints
- Authentication via JWT tokens
- Rate limiting on public APIs
- Encrypted data at rest and in transit
