## Architecture

### Components
- **MetricsCalculator** (component): Core component for calculating build metrics
- **BuildDurationCalculator** (component): Calculates average build duration metrics
- **SuccessRateCalculator** (component): Calculates build success rate metrics
- **SlowStepDetector** (component): Analyzes and identifies slow build steps


### API Contracts
- `POST /api/metrics/average-duration` — Calculate average build duration
- `POST /api/metrics/success-rate` — Calculate build success rate
- `POST /api/metrics/slow-steps` — Detect slow build steps


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client
