### Implement CacheMetricsCollector Service
- **Story:** As a system architect, I want a service that collects cache performance data from CloudFront so that we can monitor cache effectiveness
- **Priority:** P1
- **Story Points:** 5
- **Acceptance Criteria:**
  - [ ] Service successfully connects to CloudWatch API
  - [ ] Cache hit/miss counts are collected every minute
  - [ ] P99 latency measurements are calculated correctly
  - [ ] Metrics are properly formatted for storage
  - [ ] Error handling for API failures is implemented

### Create Cache Metrics API Endpoint
- **Story:** As a developer, I want an API endpoint that exposes cache performance metrics so that I can integrate them into monitoring dashboards
- **Priority:** P1
- **Story Points:** 3
- **Acceptance Criteria:**
  - [ ] GET /api/cache/status endpoint returns 200 OK with valid data
  - [ ] Response includes hit rate, P99 latency, and request count
  - [ ] Response time is under 500ms
  - [ ] Proper error responses for service unavailability
  - [ ] API is documented in Swagger/OpenAPI

- **Priority:** P2
- **Story Points:** 3
- **Acceptance Criteria:**

  - [ ] Query methods for retrieving historical data are implemented
