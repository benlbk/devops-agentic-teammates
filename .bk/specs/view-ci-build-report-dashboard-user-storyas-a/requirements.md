### Create Build Report Dashboard Page Layout
- **Story:** As a DevOps engineer, I want to see a well-organized dashboard layout so that I can easily view all CI build metrics

- **Story Points:** 3
- **Acceptance Criteria:**

  - [ ] Date range filter is positioned at the top
  - [ ] Workflow statistics table is centered on the page
  - [ ] Layout is responsive and works on different screen sizes
  - [ ] Page has proper loading states

### Implement Workflow Statistics Table
- **Story:** As a DevOps engineer, I want to view a table of workflow statistics so that I can analyze build performance metrics
- **Priority:** P0
- **Story Points:** 5
- **Acceptance Criteria:**
  - [ ] Table displays workflow name
  - [ ] Shows p50, p95, and max durations for each workflow
  - [ ] Displays success and failure counts
  - [ ] Data is properly formatted (durations in minutes, counts as integers)
  - [ ] Table supports sorting by columns

### Create Date Range Filter Component
- **Story:** As a DevOps engineer, I want to filter build statistics by date range so that I can focus on specific time periods
- **Priority:** P1
- **Story Points:** 3
- **Acceptance Criteria:**

  - [ ] Persists selected range in URL parameters

### Implement Build Statistics Service
- **Story:** As a DevOps engineer, I want the dashboard to fetch and process build statistics so that I can see accurate metrics
