## Architecture

### Components
- **DailyRecommendationJob** (service): Scheduled service that runs daily analysis and updates recommendations
- **RecommendationService** (service): Service for CRUD operations on recommendations
- **AnalysisService** (service): Service that analyzes data and generates recommendations
- **JobStatusLogger** (component): Component for logging job execution status


### API Contracts
- `POST /api/jobs/recommendations/daily` — Trigger daily recommendation update job
- `GET /api/jobs/{job_id}/status` — Get job execution status


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client

## Technology Stack
- Frontend: Next.js 14+ with TypeScript, React, Tailwind CSS
- Backend: ASP.NET Core 8+ with C#, Entity Framework Core
- Database: PostgreSQL
- Infrastructure: AWS EKS, Terraform
