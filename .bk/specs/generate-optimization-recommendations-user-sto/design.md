## Architecture

### Components
- **RecommendationGenerator** (service): Service to analyze build data and generate optimization recommendations
- **RecommendationCard** (component): UI component to display individual optimization recommendations
- **CodeSnippetViewer** (component): Component for displaying and copying code snippets


### API Contracts
- `POST /api/recommendations/generate` — Generate optimization recommendations from build analysis
- `GET /api/recommendations` — Get all optimization recommendations


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client

## Technology Stack

- Backend: ASP.NET Core 8+ with C#, Entity Framework Core
- Database: PostgreSQL
- Infrastructure: AWS EKS, Terraform
