## Architecture

### Components
- **BuildMetricsAnalyzer** (service): Core service that analyzes build data and generates metrics
- **MetricsRepository** (service): Service handling persistence of analyzed metrics
- **MetricsCalculator** (component): Component containing calculation logic for different metrics
- **HourlyAnalysisJob** (service): Scheduled job that triggers metrics analysis hourly


### API Contracts
- `GET /api/metrics/builds` — Retrieve latest build metrics analysis
- `POST /api/metrics/builds/analyze` — Trigger manual analysis of build metrics


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client

## Technology Stack
- Frontend: Next.js 14+ with TypeScript, React, Tailwind CSS
- Backend: ASP.NET Core 8+ with C#, Entity Framework Core
- Database: PostgreSQL
