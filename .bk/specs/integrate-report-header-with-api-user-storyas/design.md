## Architecture

### Components
- **ReportHeader** (component): Header component that displays report metadata
- **MetadataService** (service): Service to fetch report metadata from API
- **LoadingSpinner** (component): Loading state indicator component
- **ErrorMessage** (component): Error state display component


### API Contracts
- `GET /api/reports/{reportId}/metadata` — Fetch metadata for a specific report


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client

- Backend: ASP.NET Core 8+ with C#, Entity Framework Core
- Database: PostgreSQL
- Infrastructure: AWS EKS, Terraform
