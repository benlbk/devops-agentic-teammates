## Architecture

### Components
- **WorkflowStatsService** (service): Service to process and calculate workflow build statistics
- **StatsCache** (service): Caching layer for workflow statistics
- **StatisticsProcessor** (component): Utility component for calculating statistical metrics


### API Contracts
- `GET /api/workflow-stats` — Fetch workflow build statistics for a given date range


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client
