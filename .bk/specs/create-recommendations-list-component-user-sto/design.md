## Architecture

### Components
- **RecommendationsList** (component): Displays formatted list of actionable recommendations for SLO breaches
- **RecommendationCard** (component): Individual recommendation card with title, description and documentation link
- **RecommendationsService** (service): Service to fetch and manage recommendations based on breach type


### API Contracts
- `GET /api/recommendations` — Get list of recommendations filtered by breach type


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client
