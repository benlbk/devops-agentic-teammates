- **EmptyStateMessage** (component): Component shown when no slow steps exist

### API Contracts
- `GET /api/tests/{testId}/slow-steps` — Retrieve list of slow steps for a specific test


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client
