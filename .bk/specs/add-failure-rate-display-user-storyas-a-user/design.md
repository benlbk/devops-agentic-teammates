# Design: Add Failure Rate Display

## User Story

## Architecture

### Components
- **FailureRateDisplay** (component): Component to show job failure rate with visual indicators
- **FailureRateTooltip** (component): Tooltip showing detailed failure statistics
- **FailureRateService** (service): Service to calculate and format failure rate data


### API Contracts
- `GET /api/jobs/{jobId}/failure-stats` — Get failure statistics for a specific job


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client

## Technology Stack
- Frontend: Next.js 14+ with TypeScript, React, Tailwind CSS
- Backend: ASP.NET Core 8+ with C#, Entity Framework Core
- Database: PostgreSQL
- Infrastructure: AWS EKS, Terraform

## Security Considerations
- Input validation on all endpoints
