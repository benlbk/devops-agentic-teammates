## Architecture

### Components
- **CircuitBreakerMetricsService** (service): Service to collect and manage circuit breaker metrics
- **MetricsController** (component): REST controller to expose circuit breaker metrics
- **MetricsRepository** (component): Repository interface for storing circuit breaker metrics


### API Contracts
- `GET /api/v1/metrics/circuit-breakers` — Get metrics for all circuit breakers
- `GET /api/v1/metrics/circuit-breakers/{id}` — Get metrics for specific circuit breaker


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client
