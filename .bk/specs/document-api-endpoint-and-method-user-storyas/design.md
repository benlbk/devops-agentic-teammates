# Design: Document API Endpoint and Method

## User Story

## Architecture

### Components
- **SlowestStepsApiDoc** (component): API documentation component for the slowest build steps endpoint
- **BuildsController** (service): Controller handling build-related API endpoints


### API Contracts
- `GET /api/v1/builds/slowest-steps` — Retrieves a list of the slowest build steps across all builds


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client

## Technology Stack

- Backend: ASP.NET Core 8+ with C#, Entity Framework Core
- Database: PostgreSQL
- Infrastructure: AWS EKS, Terraform
