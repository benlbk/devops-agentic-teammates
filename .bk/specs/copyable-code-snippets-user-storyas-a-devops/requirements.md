## User Stories

### Create Code Snippet Display Component
- **Story:** As a DevOps engineer, I want to see code snippets in a formatted block so that I can easily read and understand the code
- **Priority:** P2
- **Story Points:** 3
- **Acceptance Criteria:**
  - [ ] Code is displayed in a monospace font
  - [ ] Code block has distinct styling from regular text
  - [ ] Long code lines wrap appropriately
  - [ ] Code preserves whitespace and indentation
  - [ ] Syntax highlighting is applied based on code language

### Implement Copy to Clipboard
- **Story:** As a DevOps engineer, I want to copy code snippets with a single click so that I can quickly use them in my work
- **Priority:** P2
- **Story Points:** 2
- **Acceptance Criteria:**
  - [ ] Copy button is visible on hover over code block
  - [ ] Clicking copy button copies exact code content to clipboard
  - [ ] Copy works across all major browsers
  - [ ] Copy functionality works with special characters and formatting
  - [ ] Copy button has clear visual affordance

### Add Copy Success Feedback
- **Story:** As a DevOps engineer, I want to see confirmation when code is copied so that I know the action was successful
- **Priority:** P2
- **Story Points:** 1
- **Acceptance Criteria:**
  - [ ] Success toast/notification appears when code is copied
  - [ ] Feedback is visible for 3 seconds
  - [ ] Feedback is visually distinct
  - [ ] Feedback doesn't block other UI interactions
  - [ ] Multiple copy actions show separate feedback

### Support Multiple Code Snippets
- **Story:** As a DevOps engineer, I want to see and copy multiple code snippets in a single recommendation so that I can implement multi-step solutions
- **Priority:** P2
- **Story Points:** 2
- **Acceptance Criteria:**
  - [ ] Multiple code blocks can appear in one recommendation
  - [ ] Each code block has its own copy button
  - [ ] Proper spacing between multiple snippets
  - [ ] Clear visual separation between snippets
  - [ ] All snippets maintain individual syntax highlighting
