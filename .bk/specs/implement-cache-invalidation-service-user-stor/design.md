## Architecture

### Components
- **CacheInvalidator** (service): Service to handle cache invalidation requests and communicate with CloudFront
- **InvalidationTracker** (component): Component to track and manage invalidation status
- **InvalidationModel** (model): Data model to store invalidation records
- **CreateInvalidationMigration** (migration): Database migration for invalidation tracking table


### API Contracts
- `POST /api/cache/invalidate` — Create a new cache invalidation request
- `GET /api/cache/invalidation/{id}` — Get status of a specific invalidation request


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client
