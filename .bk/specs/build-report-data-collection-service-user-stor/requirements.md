- **Story:** As a system administrator, I want an automated service to collect workflow run data so that we have up-to-date build information for analysis
- **Priority:** P0
- **Story Points:** 5
- **Acceptance Criteria:**

  - [ ] Stores collected data in BuildMetricsDB
