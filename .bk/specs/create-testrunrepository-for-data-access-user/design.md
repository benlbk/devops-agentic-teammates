## Architecture

### Components
- **TestRunRepository** (service): Repository service for accessing and querying test run data
- **TestRunRepositoryTests** (component): Unit test suite for TestRunRepository


### API Contracts
- `GET /api/test-runs` — Fetch workflow runs for a date range
- `GET /api/test-runs/failure-rates` — Get job failure rates
- `GET /api/test-runs/step-durations` — Get step duration statistics


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client
